### Доступ к API покупается отдельно

С 4 сентября 2026 года подписка на сайт доступа к API не даёт: API продаётся
отдельным пакетом. Пакет можно купить на любом тарифе, включая бесплатный, — витрина
с составом и ценами: [пакеты API](https://telemetr.me/premium-api?utm_source=user_api_docs&utm_medium=postman),
оформление — в [профиле](https://telemetr.me/profile/api/buy?utm_source=user_api_docs&utm_medium=postman).

Если пакета нет, любой метод отвечает **HTTP 429** и телом
`{"status": "error", "response": {"code": 0, "message": "Доступ к API не подключён…"}}`.
Это не превышение лимита и не временный сбой: повторы не помогут, нужен пакет. Тем, кто
оплатил подписку сайта до 4 сентября, лимиты сохранены до конца уже оплаченного периода.

Попробовать методы без покупки можно на нашем канале
[@telemetr_me](https://t.me/telemetr_me): пробный доступ отвечает по нему одному, с
небольшими лимитами, и даётся новым учётным записям на бесплатном тарифе. Формы ответов
в пробном режиме те же, что на платном пакете, — по ним видно, есть ли в наших данных
то, что вам нужно.

Сколько объёма осталось, всегда показывает `GET /v1/limits`, а после каждого вызова —
заголовки `X-RateLimit-*`.

## Что здесь лежит

- `v1-Telemetr-API.http` — запросы для HTTP-клиента JetBrains. Переменные берутся из
  `http-client.env.json`: подставьте свой ключ в `bearerToken` и работайте.
- `v1-Telemetr-API.postman_collection.json` — коллекция Postman. Она **собирается из
  спецификации** сервиса, а не пишется руками: в ней все методы, все параметры и примеры
  ответов, включая отказы. Обновляется вместе с API.
- `v1-Telemetr-API.postman_environment.json` — окружение к ней.

## Площадка MAX

Кроме Telegram, API отдаёт данные мессенджера MAX. Это отдельный продукт: **свой ключ, свой
пакет, свой счёт квоты**. Площадку задаёт ключ — параметр `platform` можно не присылать вовсе,
а если присылаете, его значение обязано совпадать с площадкой ключа.

По MAX работают семь методов: карточка канала, статистика, подписчики, лента публикаций, поиск
по каталогу, справочник категорий и остаток лимитов. Остальные отвечают отказом с кодом 35.
Часть показателей по MAX не считается вовсе — индекс цитирования, упоминания, пересылки, доля
премиум-подписчиков, скоринг, рекламный охват: эти поля всегда пустые, и это не ошибка.

Примеры — в конце `v1-Telemetr-API.http`, раздел «Площадка MAX». Подробности — в
[документации](https://api.telemetr.me/doc), раздел «Площадка MAX».
